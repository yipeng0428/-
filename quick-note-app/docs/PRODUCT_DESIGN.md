# Quick Note App 产品设计文档 (Product Design)

## 1. 产品定位与目标
本产品是一款主打**轻量、极速、多平台同步**的现代记事本应用。
主要目标用户是需要随时随地记录灵感、待办事项、会议纪要等碎片化信息的群体。
核心策略：**移动端优先 (Mobile-First)**，同时提供网页端同步，并支持打包为 Windows 桌面版 (通过 Electron/Tauri 等技术)。

## 2. 核心功能设计 (Core Features)

参考目前知名的记事本应用 (如 Apple Notes, 备忘录, 印象笔记, Notion, Flomo 等)，本产品将包含以下核心功能：

### 2.1 基础记录体验
- **多格式支持**：富文本编辑 (加粗、斜体、列表、待办事项 Checkbox 等)，支持 Markdown 快捷语法。
- **多媒体附件**：支持插入图片、语音录音转文字 (依赖系统 API 或是 Web API)。
- **分类与标签**：支持文件夹层级分类以及灵活的多标签系统。

### 2.2 核心特色：独立“速记”功能 (Quick Note)
这是本应用最核心的差异化功能，旨在解决“打开应用太慢导致灵感流失”的痛点。

- **唤出方式**：
  - **手机端**：支持桌面小组件 (Widget) 直接点击呼出、支持系统级快捷瓷贴 (Quick Settings Tile, Android)、支持锁屏界面快速启动 (如果系统允许)。还可以是一个悬浮窗/悬浮球，随时点击弹出极简输入框。
  - **PC端**：通过全局快捷键 (如 `Ctrl + Shift + N` / `Cmd + Shift + N`) 瞬间呼出一个不干扰当前工作流的极简悬浮输入框。
- **记录形式**：纯文本、快速拍照、语音一键录制。
- **处理逻辑**：速记内容自动存入名为“收件箱 (Inbox)”或“速记”的默认文件夹，并自动打上时间戳。不需要用户在记录时思考分类。后续用户可以在闲暇时间整理这些零散的速记。

### 2.3 组织与查找
- **全局搜索**：支持标题、正文内容的极速搜索。未来可加入 OCR 搜索图片内文字。
- **视图切换**：列表视图、瀑布流卡片视图。
- **置顶与收藏**：高频使用的笔记可以置顶。

### 2.4 同步与多平台 (Cross-Platform Strategy)
- **同步机制**：实时/增量同步，支持离线模式 (Offline-First)。用户在无网状态下依然可以流畅使用所有功能，恢复网络后后台自动同步。
- **平台支持**：
  - **移动端 (首发)**：iOS / Android，优先保证触屏体验的极致流畅。可以考虑使用 React Native, Flutter 或 PWA 作为技术栈。
  - **Web 端**：提供完整的管理和编辑功能，方便在任何设备上通过浏览器访问。
  - **桌面端 (Windows exe / macOS app)**：为了提供本地化体验和全局快捷键功能，提供独立安装包。

## 3. 交互与 UI 设计 (UI/UX)
- **极简主义 (Minimalism)**：界面留白，减少视觉干扰，让内容成为绝对的核心。
- **暗黑模式 (Dark Mode)**：提供系统级自适应的亮色/暗色主题。
- **手势操作**：移动端大量使用手势，例如左滑删除/归档，右滑置顶等，提升单手操作效率。

## 4. 技术栈考量 (建议)
- **前端**：考虑到跨平台和 Web 同步需求，可采用 React Native (Mobile) + React/Vue (Web) 的方案。为了更快验证产品，PWA (Progressive Web App) 也是初期极佳的选择，搭配 Capacitor 可以快速打包为 App。
- **桌面端**：Tauri (比 Electron 更轻量) 或者 Electron。
- **后端/数据同步**：可考虑无后端 (BaaS) 方案如 Supabase, Firebase，或者使用基于 CRDT (Conflict-free Replicated Data Type) 的本地优先同步框架 (如 Yjs) 来解决多端冲突和离线编辑问题。

## 5. 后续演进路线 (Roadmap)
- **Phase 1**：完成移动端单机版，跑通核心“速记”和基本文本/图片编辑，验证交互。
- **Phase 2**：接入云端同步，提供 Web 端访问。
- **Phase 3**：推出 Windows/macOS 桌面客户端，完善全局“速记”快捷键。
- **Phase 4**：加入语音转文本、AI 智能分类/总结等高级特性。
