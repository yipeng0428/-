# 产品设计文档：Quick Note App (暂定名)

## 一、 产品定位与目标
本应用致力于成为一款轻量级、跨平台、以“极速记录”为核心体验的个人记事本应用。它融合了 Flomo 的碎片化记录优势、Google Keep 的便签式直观浏览以及 Notion 的结构化潜力，旨在帮助用户无缝捕捉灵感、管理日常事务并构建个人知识库。

**核心目标：**
- **Mobile First（移动优先）：** 满足随时随地的记录需求，移动端体验为重中之重。
- **全平台同步：** 支持移动端（App/PWA）、Web端以及未来的桌面端（Windows/macOS），实现数据无缝漫游。
- **独立速记（Quick Note）：** 提供全局或独立的快捷输入入口，做到“呼之即来，挥之即去”。

## 二、 核心功能设计

### 1. 独立速记功能 (Quick Note) - 核心亮点
这是区别于传统记事本的最核心功能，旨在最大化降低记录的启动成本。

- **触发方式：**
    - **移动端 (App)：** 通过桌面小组件 (Widget)、通知栏快捷方式、或系统级分享菜单（如分享文本/链接到应用）直接呼出速记悬浮窗，无需完整启动App主界面。
    - **PC/Web端：** 支持全局快捷键呼出速记浮窗，或浏览器扩展/PWA快捷方式一键启动。
- **交互形态：**
    - 极简的输入框，支持文本、语音转文字、剪贴板快速粘贴。
    - **即写即存：** 输入完毕后，可点击发送或直接关闭，内容自动后台存入“收件箱 (Inbox)”。
    - **无感标签：** 支持在速记内容中使用 `#标签` 快速分类，无需额外点击分类按钮。

### 2. 基础笔记管理
- **流式浏览 (Timeline/List/Grid)：** 类似瀑布流或时间线，最新记录优先展示。支持切换网格视图（类似 Google Keep）。
- **多媒体支持：** 文本、待办列表 (Checklist)、图片、音频附件。
- **分类与组织：**
    - **收件箱 (Inbox)：** 所有速记和未分类内容的默认归宿，鼓励用户定期整理。
    - **标签系统 (Tags)：** 灵活的分类方式，支持嵌套标签（如 `#工作/项目A`）。
    - **置顶与归档：** 将重要笔记置顶，将不再需要的笔记归档以保持界面整洁。
- **全文搜索：** 快速定位历史记录，支持关键词、标签、日期等维度的组合搜索。

### 3. 多端同步与数据安全
- **云端同步：** 基于稳健的后端服务（如 Node.js + WebSocket/REST API）实现秒级多端同步。
- **离线可用：** 应用(特别是在移动端)必须支持完整的离线使用。无网状态下记录的内容保存在本地，连网后自动合并同步。
- **数据导出：** 支持导出为 Markdown 或 JSON 格式，保障用户的数据所有权。

## 三、 技术选型建议 (初步)

为了实现跨平台和移动优先，同时保证开发效率，建议采用以下技术栈：

- **前端/移动端 (Cross-platform)：**
    - **方案A (PWA + Web 技术栈)：** React/Vue/Svelte + TailwindCSS。开发成本极低，天然跨平台，可通过 PWA 安装到手机，体验接近原生。
    - **方案B (React Native / Expo)：** 如果对移动端性能和原生交互（如桌面小组件）要求极高，可选择 RN。可以实现“一套代码，iOS/Android 双端运行”，后续也可兼顾 Web 端。
    - **桌面端延伸：** 如果采用方案A，可借助 Tauri 或 Electron 轻松打包为 Windows/macOS 客户端；如果采用方案B，RN 也有桌面端支持或复用 Web 端。
- **后端服务：**
    - Node.js (Express/NestJS) 或 Go。
    - 数据库：PostgreSQL (关系型数据) 或 MongoDB (文档型数据更适合灵活的笔记结构)。
    - 对于敏捷开发，也可考虑使用 BaaS 服务如 Supabase 或 Firebase，它们自带实时同步和离线支持。

## 四、 演进路线图 (Roadmap)

### Phase 1: MVP (最小可行性产品) - 专注移动端 Web/PWA
- 搭建基础架构 (前端框架选型，本地存储设计)。
- 实现核心的 **速记功能** (支持文本输入，本地存储)。
- 实现基本的流式列表视图和简单的标签化。
- 目标：自己可以用起来，体验“快”的记录感受。

### Phase 2: 云端化与全平台
- 接入后端服务，实现多端实时同步。
- 完善 Web 端界面，使其适配桌面端大屏浏览。
- 增加用户账号系统。

### Phase 3: 体验深化与原生化
- (可选) 将 PWA 升级为 React Native 应用，以获得更好的移动端原生体验（如真正的系统级小组件唤醒速记）。
- 打包发布 Windows/macOS 独立桌面客户端。
- 增加富文本编辑、Markdown 支持、全文搜索优化。

## 五、 总结

该记事本应用的设计理念是 **“少即是多” (Less is more)**。在交互上做减法，让记录动作尽可能顺滑无阻力（尤其是独立速记功能）；在数据组织上提供灵活的标签系统，而不强加复杂的层级结构。这将是一个非常适合个人使用并伴随个人需求不断迭代的绝佳项目。
