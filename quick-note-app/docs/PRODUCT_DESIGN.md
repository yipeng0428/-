# 记事本 APP 产品设计文档 (Quick Note App)

## 1. 产品概述
这是一款以移动端优先（Mobile-First），支持多端同步（手机端、网页端、PC桌面端）的现代记事本应用。其核心特色在于**“全局速记（Quick Note）”**功能，让用户能够在任何场景下以极低的阻力进行灵感捕捉和快速记录。

## 2. 目标平台
- **移动端（核心）**：iOS & Android。作为首发和核心平台。
- **网页端（Web）**：在任何设备上通过浏览器访问并同步数据。
- **桌面端（PC/Win）**：提供可安装的桌面应用（如 .exe），支持全局快捷键。

## 3. 核心功能设计

### 3.1 独立呼出的“速记（Quick Note）”功能
这是本应用最具差异化的核心特性，要求**极快启动、无缝记录、用完即走**。
- **移动端实现方式**：
  - **桌面小组件（Widget）**：提供直接输入框或一键录音的小组件。
  - **通知栏常驻/快捷磁贴（Android）**：下拉通知栏一键呼出悬浮窗输入。
  - **锁屏界面捷径（iOS/Android）**：无需解锁即可记录（类似系统相机）。
  - **分享意图（Share Intent）**：在其他APP中，选中文字或图片，直接“分享到速记”。
- **桌面端（Win）实现方式**：
  - **全局快捷键（如 `Ctrl + Alt + N`）**：随时呼出一个轻量级的悬浮输入框，无需打开主程序界面。
- **速记内容类型**：支持纯文本、语音转文字、快速拍照。

### 3.2 基础记事与管理
- **富文本编辑**：支持加粗、列表、待办打勾、插入图片。
- **分类与标签**：支持文件夹层级和多重标签（如 `#灵感`, `#工作`）。
- **全文搜索**：支持极速搜索，高亮匹配内容。
- **云端同步**：账号登录后，所有笔记秒级同步。

### 3.3 UI/UX 设计原则
- **极简主义**：减少视觉噪音，核心界面只有“新建”按钮和笔记列表。
- **手势操作**：移动端支持侧滑删除、长按归档等主流手势。
- **暗黑模式**：原生支持跟随系统切换日间/夜间模式。

## 4. 技术栈选型建议（供参考）
为了实现多端同步和高效开发，建议采用跨平台技术栈：

- **前端/移动端**：
  - **React Native (Expo)** 或 **Flutter**：一套代码同时打包 iOS 和 Android，并且可以输出 Web 版。
  - **PWA (渐进式Web应用)**：如果初期想极低成本验证，可以先做适配移动端的 Web 网页，并支持离线访问。
- **桌面端**：
  - **Tauri** 或 **Electron**：打包现有的 Web 代码，支持调用操作系统底层的“全局快捷键”来实现独立悬浮速记。
- **后端与同步**：
  - **Supabase / Firebase**：提供开箱即用的实时数据库、用户认证和云端存储功能。
  - **CRDT (无冲突复制数据类型)**：如 Yjs，实现优雅的多端离线编辑和合并同步。

## 5. 开发路线图 (Roadmap)
- **Phase 1 (MVP)**：移动端单机版应用 + 基础富文本编辑 + 本地速记小组件。
- **Phase 2**：引入用户系统与云端数据同步。
- **Phase 3**：推出 Web 端，完善多端体验。
- **Phase 4**：开发基于 Tauri/Electron 的 Windows 桌面端，实现全局快捷键速记。
