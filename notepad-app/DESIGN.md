# 个人跨平台记事本 APP 设计文档 (Notepad App Design)

## 1. 需求背景 & 目标
开发一款属于自己的记事本 APP，首要目标是满足移动端（手机）的使用，并且能够支持网页端同步，未来支持打包为 Windows 本地应用 (exe)。
核心创新点：独立且快捷的**“速记功能”**，能够随时呼出进行快速记录。

## 2. 核心功能设计 (Feature List)

借鉴当前知名笔记应用（如 Google Keep, Apple Notes, Notion, 备忘录等），规划以下功能：

### 2.1 基础笔记功能
* **文本编辑:** 支持基础的富文本编辑（加粗、斜体、列表、待办事项、标题层级）。
* **多媒体支持:** 允许插入图片、语音录音（后续版本可加入语音转文字）。
* **分类与标签:** 支持文件夹分类和灵活的标签 (Tags) 系统，方便后续查找。
* **搜索功能:** 全局快速搜索（支持按标题、内容、标签检索）。
* **置顶与收藏:** 重要笔记一键置顶或加入收藏。

### 2.2 核心特性：独立速记功能 (Quick Note)
这是本应用最核心的区别和亮点。为了在手机端达到“最快记录”的要求：
* **实现方式 (Android端):**
  * **桌面小组件 (Widget):** 提供一个小巧的桌面快捷按钮，点击直接弹出半透明或浮层的输入框，无需完全打开主APP。
  * **快捷设置面板 (Quick Settings Tile):** 在下拉通知栏中添加一个快捷开关，点击立刻弹出输入悬浮窗。
  * **悬浮窗模式 (Floating Window / Bubble):** 类似聊天气泡，长期悬浮在屏幕边缘，点击即可输入。
* **实现方式 (iOS端):**
  * **锁屏/桌面小组件 (Widgets):** 快速进入编辑模式。
  * **Share Extension (分享扩展):** 在其他APP中复制文字后，可以通过系统的“分享”菜单直接发送到速记本。
  * **快捷指令 (Shortcuts):** 深度集成 iOS 快捷指令，实现语音唤醒（如“Siri, 记录一下...”）。
* **速记保存机制:** 速记内容不需要写标题，默认按时间戳命名（如“速记 2024-05-20 14:00”），并统一存放在“收件箱 (Inbox)”或“速记”分类中，供用户日后整理。

### 2.3 云端与同步
* **多端同步:** 移动端（主）、网页端、PC端通过统一的后端数据库实时同步。
* **离线模式:** 本地优先 (Local-first) 架构，断网时可正常读写，联网后自动同步冲突解决。

## 3. 技术栈选型 (Technology Stack)

为了实现**一套代码、多端运行**（Mobile, Web, Windows Desktop），推荐以下技术选型：

### 3.1 前端 / 客户端 (Frontend)
* **首选方案：Flutter**
  * **理由:** 谷歌开源的跨平台框架，性能极其接近原生。一套 Dart 代码可完美编译为 iOS, Android, Web，以及 Windows 本地 exe。
  * **优势:** 丰富的 UI 组件库，极佳的跨平台一致性，对桌面端和 Web 端支持已经非常成熟。
* **备选方案：React Native (配合 React Native Web + Electron/Tauri)**
  * **理由:** 如果你有丰富的前端 (React) 经验，RN 能够很快上手移动端。
  * **劣势:** 要支持 Web 需要引入 RN-Web，要支持 Windows 需要用 Electron 或 Tauri 打包，技术栈较为碎片化。
* **存储 (Local Storage):** SQLite (通过 `sqflite` 或 `drift`) / Hive，实现本地优先。

### 3.2 后端 / 云端 (Backend)
* **首选：Supabase 或 Firebase**
  * **理由:** 提供开箱即用的 Auth (用户登录认证)、PostgreSQL 数据库 (Supabase)、实时数据订阅和 Storage (图片存储)。极其适合个人开发者快速搭建支持多端同步的后端。
* **自建后端:** Node.js (Express/NestJS) + PostgreSQL / MongoDB (如需完全自己控制数据)。

## 4. 第一阶段 (MVP) 开发路线图

既然最想先做的是**手机端**和**速记功能**，建议按照以下步骤进行：

1. **环境搭建与基础架构:** 初始化 Flutter 项目，配置 Supabase 后端连接。
2. **核心 UI 开发:** 完成主界面的笔记列表、笔记详情/编辑页。
3. **独立速记开发 (重点):**
   - 编写原生通道 (Method Channel) 接入 Android 桌面小组件或 iOS Widget。
   - 开发极简的“速记输入面板”。
4. **本地存储与同步:** 实现本地离线保存，并与 Supabase 打通进行云端同步。
5. **测试与发布:** 进行多机型测试，导出 Android APK 进行试用。
