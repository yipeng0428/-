# 记事本 App 设计文档 (Notepad App Design Document)

## 1. 产品愿景与概述 (Product Vision & Overview)
**目标:** 打造一款个人专属的跨平台记事本应用。优先保障极致的手机端体验，同时支持网页端同步，并提供可安装在本地的 Windows 客户端（.exe）。
**核心卖点:** 独立的“速记 (Quick Memo)”功能，允许用户在不打开主应用界面的情况下，进行瞬间记录，捕捉转瞬即逝的灵感。

## 2. 核心功能设计 (参考主流笔记应用如 Apple Notes, Evernote, Notion 等)

### 2.1 基础与进阶功能 (Core & Advanced Features)
*   **富文本编辑:** 支持基础排版（加粗、斜体、下划线）、列表（有序/无序）、待办事项（Checkboxes）和多级标题。
*   **多媒体支持:** 允许插入图片、录音（语音备忘录）和简单的手写涂鸦。
*   **组织与管理:**
    *   **文件夹与标签体系:** 支持多层级文件夹和灵活的标签管理。
    *   **全局搜索:** 快速检索标题和正文内容。
    *   **置顶与收藏:** 重要笔记一键置顶。
*   **跨端同步 (Sync):** 手机、网页、电脑端实时无缝同步。
*   **离线优先 (Offline-First):** 即使没有网络也能查看和编辑所有笔记，网络恢复后自动后台同步。
*   **隐私与安全:** 支持应用锁（面容 ID/指纹/密码），并可对单篇私密笔记进行单独加密。

### 2.2 核心特色：独立“速记”功能 (Standalone "Quick Memo")
为了满足快速记录的需求，“速记”模块在架构上与主应用解耦，追求极致的启动速度和最少的交互层级。
*   **呼出方式设计:**
    *   **Android:** 下拉通知栏快捷开关 (Quick Settings Tile)、桌面悬浮窗或长按桌面图标呼出快捷方式 (App Shortcuts)。
    *   **iOS:** 锁屏小组件 (Lock Screen Widget)、控制中心快捷指令 (Control Center Shortcut) 或配合 Action 按钮。
    *   **Windows (桌面端):** 全局系统快捷键 (例如 `Ctrl + Alt + N`) 直接呼出居中悬浮输入框。
*   **交互体验 (UX):**
    *   呼出后直接激活键盘，光标就绪。
    *   极简界面，只有输入框、完成按钮和（可选的）录音按钮。
    *   **自动归档:** 速记内容自动保存在默认的“速记箱 (Inbox)”文件夹中，无需在记录时花时间分类。

## 3. 技术栈建议 (Technical Architecture & Tech Stack)

鉴于您的需求是包含手机端、网页端和 Windows 客户端，推荐采用大前端跨平台方案。

### 3.1 前端技术栈 (Frontend)
*   **手机端 (iOS & Android):** **Flutter** 或 **React Native (RN)**。
    *   *推荐 Flutter:* 性能接近原生，UI 在双端表现高度一致，适合做界面精美的笔记应用。
*   **网页端 (Web):** **React.js** 或 **Vue.js**。可以构建为 PWA (渐进式 Web 应用)。
*   **Windows 桌面端:** **Tauri** 或 **Electron**。
    *   *推荐 Tauri:* 使用网页前端技术构建桌面应用，但底层使用 Rust，打包出的 `.exe` 体积极小（通常只有几 MB），内存占用远低于 Electron，非常适合需要常驻后台的笔记软件。

### 3.2 后端与同步架构 (Backend & Sync)
*   **BaaS (后端即服务):** 推荐使用 **Supabase** (开源的 Firebase 替代品) 或 **Firebase**。
    *   它们提供了现成的用户认证系统、实时数据库（PostgreSQL/NoSQL）和云存储（存图片/语音）。
    *   极大地降低了自己从头搭建后端接口和同步逻辑的成本。
*   **离线存储:** 移动端使用 SQLite (配合 Flutter/RN 的本地数据库插件) 实现本地持久化存储。
*   **同步机制:** 采用离线优先架构。本地修改会带上时间戳，网络连通后与云端进行增量同步（可采用 Last-Write-Wins 策略或更复杂的 CRDT 算法解决多端冲突）。

## 4. 研发路线图 (Development Phases)

*   **Phase 1: MVP (最小可行性产品) - 专注移动端**
    *   完成手机端 App 的基础框架搭建。
    *   实现本地文本编辑、保存功能（暂不联网）。
    *   重点攻克并实现“速记”呼出与保存功能。
*   **Phase 2: 云端同步与网页版**
    *   接入 Supabase，实现账号注册登录。
    *   实现本地数据与云端数据库的同步。
    *   发布 Web 网页版，共享云端数据。
*   **Phase 3: 桌面端与功能完善**
    *   使用 Tauri 将 Web 版打包为 Windows `.exe` 安装程序，加入全局快捷键呼出速记。
    *   加入图片上传、富文本排版优化、标签系统等进阶功能。
